# AGENTS.md

This folder is [YOUR NAME]'s operating system: who they are, what they run, what they
decided, and how their recurring jobs get done. Any agent can pick it up and work.

This file is a map. It says where things are, not what they say. Read the file it points to.

## Read first, every time

1. This file
2. `STATE.md`: what's true right now. If it disagrees with something else, it wins.
3. `context/me.md`: who I am and how I talk
4. `context/rules.md`: the rules that never change

Stop there unless the task needs more.

## Where things are

| You need | Go to |
|---|---|
| What's true now, what's stuck, what's next | `STATE.md` |
| Why something is the way it is | `DECISIONS.md` (newest first; don't reopen a settled call) |
| A person, company or project | `notes/`, one page each |
| Something I dumped to look at later | `inbox.md` |
| How to do a recurring job | `skills/<name>/SKILL.md` |

If you had to search for something that should have been in this table, add the row.

## When you finish a task

Before you tell me it's done, write down what changed:

| What changed | Where it goes |
|---|---|
| Something true right now | `STATE.md` (rewrite the line) |
| A call I made, and why | `DECISIONS.md` (add it at the top) |
| A fact about a person, company or project | its page in `notes/` |

Then say what you wrote to, or say "nothing lasting changed" and why.

## Task states

Working, Blocked (ends in a question I can answer in one word), or Done (it's true and you
can show me). Nothing else.
